# C++ Algorithms & Data Structures

Solutions to 11 assignments from the Programming Methods course at university,
written in C++ (~3,400 lines). Each folder has its own README with details.

| # | Topic |
|---|-------|
| 1 | Array processing, maximum submatrix |
| 2 | Grid matching with error minimization (+ Python plots) |
| 3 | Binary search, interpolation search, duplicate removal |
| 4 | Stack (dynamic array, linked list, std::stack), infix ↔ RPN converter |
| 5 | Graph representations: incidence matrix and lists |
| 6 | Search in a sorted 2D matrix (iterative and recursive) |
| 7 | Pseudorandom number generators (LCG, additive) |
| 8 | Knapsack: dynamic programming and recursion |
| 9 | 0/1 knapsack: backtracking and branch and bound |
| 10 | Huffman coding |
| 11 | Sorting algorithm comparison (heap sort, quicksort, shaker sort) |

## Build
g++ -std=c++17 *.cpp -o program
